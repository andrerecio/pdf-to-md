# I/O Contract

## Input
- A single PDF file path passed to `scripts/extract_pdf_to_md.py`.

## Output tree
```
outputs/
  <stem>/
    text.mmd            # Nougat-OCR Markdown output
    figures.md          # Docling Markdown output (base64 images)
    figures_decoded.md  # Docling Markdown with image links
    figures/            # Decoded image files
      figure-001.png
      figure-002.png
    combined.md         # Nougat markdown with Docling figures appended + inline footnotes
    combined_for_tex.md # Cleaned Markdown for Pandoc (optional)
    combined.tex        # LaTeX output (optional, via Pandoc)
```

## Semantics
- `combined.md` is the final merged output. It is based on Nougat Markdown (text/math/tables) with Docling figure blocks appended under `## Figures` and Docling footnotes inserted inline as Markdown footnotes (unplaced footnotes are appended under `## Footnotes (Unplaced)`).
- Math normalization to `$...$`/`$$...$$` only happens when `--normalize-math` is used.
- `combined_for_tex.md` is generated by `scripts/prepare_md_for_latex.py` to fix unclosed fences before Pandoc.
- `figures_decoded.md` is the preferred base when you want external image files instead of base64.
